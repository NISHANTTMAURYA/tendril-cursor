A zero-dependency physics engine combining Ricardo Mendieta's SVG gooey ink dynamics and text-inverting lens with Motion Bench's frame-rate independent kinematics. Features 1:1 natural pointer tracking, multi-checkpoint waypoint weaving, phone touch trails, and severed falling ropes.

⚓ 2-Stage Triple-Tap Anchor & Falling Physics Rope:

Triple-click anywhere to pin the tail at that spot. Stretch the cord across the page, then triple-click again to sever the cord into an independent falling rope!

📍 Multi Anchor Weaving Mode Triple-tap (or click "Drop Anchor") to start. Each subsequent click plants a new waypoint. Rassi droops naturally like water when loose, and pulls tight when stretched!
🎯 One Anchor Mode (Follows) Only 1 anchor pin is maintained. Triple-tap to drop anchor; clicking anywhere new smoothly glides the anchor to the new spot without ever breaking the cord!
📜 Scroll-Locked Physics Scroll up or down freely! All planted anchors, connecting spans, and severed falling ropes stay locked in place relative to page content instead of floating statically.
📱 Mobile Touch & Spills Touch and drag across the screen to draw the liquid rope trail; tap anywhere to trigger pressurized liquid splashes and cascading gravitational spills!

Rope Tension (Lag)
36 ms
segTau : number (ms) Default: 36 · Range: 15–80ms

Frame-rate independent exponential smoothing lag time constant per segment. Lower (15ms) = tight, snappy cursor follow; Higher (80ms) = loose floating trailing cord.

Tension Sensitivity
1.0x
ropeTensionSensitivity : number Default: 1.0 · Range: 0.2–2.5x

Multiplier for dynamic tension build-up when cursor stretches away from anchor pins. 2.5x snaps spans taut rapidly; 0.2x keeps the cord relaxed and loose.

Slack / Water Sag
0.42
ropeSlack : number (fraction) Default: 0.42 · Range: 0.10–0.70

Maximum slack fraction when cursor is close to anchor pins. Governs catenary sag depth and gravitational water drooping.

Tendon Thickness
9 px
strokeWidth : number (px) Default: 9 · Range: 4–18px

Base physical SVG stroke width of the central tendon spine. Features Poisson necking (thins down organically as cord stretches over long spans).

Gooey Viscosity (Blur)
7 px
gooeyBlur : number (px) Default: 7 · Range: 2–14px

SVG feGaussianBlur radius in the #goo filter. Merged with high alpha contrast (gooeyContrast: 34) to fuse vertebrae into organic liquid rubber surface tension.

Severed Rope Gravity
0.42
severedRopeGravity : number Default: 0.42 · Range: 0.15–0.95

Downward gravitational acceleration applied to joints of severed falling ropes during Verlet integration physics simulation.

Spill Drops Count
16 drops
spillCount : number Default: 16 · Range: 6–36 drops

Number of viscous liquid drops erupted per pointer click or mobile touch tap. Drops arc upward with velocity and cascade downward under gravity.

Rope Offset Capacity
6000 px
offsetSize : number (px) Default: 6000 · Range: 1000–15000px

Extra pixel offset buffer added to physical rope capacity on top of page/screen dimensions. Allows extensive weaving down tall pages before FIFO limits pop older pins.

Page Length Scale
1.15x page
pageLengthRatio : number Default: 1.15 · Range: 0.5–2.5x

Multiplier applied to total document scroll height (document.documentElement.scrollHeight). Allows the rope to dynamically stretch across the entire scrollable page height without breaking.

Complete options table supported by the Tendril constructor

Option / Method Type Default Description
color String '#10b981' Primary cursor head and rope color (Emerald Green default).
secondaryColor String '#06b6d4' Secondary tail gradient color (Cyan default).

tripleTapAnchor Boolean true Triple-tap to drop anchor and release all into severed falling rope.
preventTextSelectOnTap Boolean true Automatically disables text/word highlighting during rapid multi-taps and anchoring so text doesn't turn blue.
usePageLength Boolean true Dynamically factors the entire scrollable page height (scrollHeight) into maximum rope capacity, allowing continuous stretching down tall pages.
offsetSize Number 6000 Extra pixel offset capacity added to the rope length to allow continuous weaving across multiple screen journeys.
ropeLengthOffset Number 6000 Extra pixel offset capacity added on top of screen/page diagonal.
pageLengthRatio Number 1.15 Multiplier factor applied to scrollable page length when calculating rope limits.
ropeSlack Number 0.42 Maximum slack fraction when cursor is close to anchor pins (controls catenary sag depth).
ropeMinSlack Number 42 Minimum baseline droop offset in px so short cord spans still sag organically.
ropeTensionSensitivity Number 1.0 Developer sensitivity multiplier for rope tightening and loosening (0.2 = loose/sluggish, 1.0 = standard, 2.5 = hyper-reactive).

spillCount Number 14 Number of liquid drops spawned per spill.

releaseAllAndDrop() Method — Detaches rope from all checkpoints and severs it into Verlet falling gravity.
